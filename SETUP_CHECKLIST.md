# Checklist de instalación

- [ ] Crear repositorio GitHub.
- [ ] Subir todos los archivos.
- [ ] Habilitar **Read and write permissions** para Actions.
- [ ] Ejecutar manualmente **Monitor Zelda stock** una vez.
- [ ] Confirmar que se creó la rama `status`.
- [ ] Abrir `status.json` y verificar que aparecen las tiendas.
- [ ] Copiar `mobile/.env.example` a `mobile/.env`.
- [ ] Sustituir `TU_USUARIO/TU_REPO` en `EXPO_PUBLIC_STATUS_URL`.
- [ ] Ejecutar `npm install` dentro de `mobile`.
- [ ] Ejecutar `npx expo start`.
- [ ] Opcional: configurar Telegram en GitHub Secrets.
- [ ] Opcional: crear proyecto EAS y configurar Expo Push.
